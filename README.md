# Долгописатель 📖

Двухустройственное чтение: ноутбук показывает книгу, телефон работает как пульт.

## Возможности

- создание комнаты с 4-символьным кодом;
- подключение телефона по коду;
- кнопки «Назад», «Вперёд» и «Пауза»;
- переход на конкретную страницу;
- синхронизация через WebSocket;
- адаптивный интерфейс для ноутбука и телефона.

## Запуск

```bash
npm install
npm start
```

Открой `http://localhost:3000` на ноутбуке. Для телефона сервер должен быть доступен по сети/через интернет.

> Комнаты сейчас хранятся в памяти сервера. После перезапуска сервера активные сессии исчезают.
